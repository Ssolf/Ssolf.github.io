## Uso local
1. Clona el repositorio:
   ```
   git clone https://github.com/Ssolf/Ssolf.github.io.git
   ```
2. Abre `index.html` en tu navegador, o usa una extensión tipo "Live Server".
3. No requiere instalación de dependencias, `npm` ni paso de compilación.

## Publicación con GitHub Pages
Este repositorio usa el nombre especial `Ssolf.github.io`, por lo que GitHub Pages lo publica automáticamente como sitio de usuario:

1. Ve a **Settings → Pages** en este repositorio.
2. En "Source", selecciona **Deploy from a branch**.
3. Selecciona la rama **`main`** y la carpeta **`/ (root)`**.
4. Guarda. El sitio queda disponible en:
   ```
   https://ssolf.github.io/
   ```
